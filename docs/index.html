Nghe trước, tải sau.
Không đoán mò chất lượng.

Mọi thứ Sonora làm đều hiện rõ: nguồn là gì, chất lượng thật bao nhiêu, file nằm ở đâu.

Import preview

Dán link, xem danh sách bài, nghe thử đúng luồng sẽ tải về, chọn bài trước khi tải.

Không tự convert

Mặc định giữ nguyên luồng tốt nhất của nguồn. Chỉ convert khi bạn chọn — kèm cảnh báo nếu vô ích.

File gốc khi có thể

Tự lấy file gốc nghệ sĩ cho tải thay vì bản stream nén.

Thư viện local

Favorites, playlists, folders, tìm kiếm, lọc theo chất lượng. Kéo thả file/folder để thêm.

Biết file ở đâu

Mỗi bài hiện đường dẫn thật, mở trong Finder/Explorer một cú bấm.

Huỷ an toàn

Huỷ bất kỳ lúc nào. Sonora không bao giờ ghi đè file bạn đã có.

Badge nói thật.

Badge hiển thị chất lượng thực tế của nguồn — kể cả khi bạn đã convert. Một file FLAC tạo từ AAC 160k vẫn ghi “from AAC 160k”.

FLAC 24-bit

Lossless hoặc file gốc — không mất dữ liệu.

AAC 256k

Nén có mất dữ liệu nhưng chất lượng nghe tốt.

AAC 96k

Nén mạnh hoặc không xác định được nguồn.
